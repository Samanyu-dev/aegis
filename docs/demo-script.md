# AEGIS — 3-Minute Live Hackathon Demo Script

This script is structured to ensure every judge is wowed within **90-180 seconds** of opening the live demo. It aligns perfectly with the judging criteria: *Security & Compliance (Primary)*, *GTM Intelligence*, and *Finance & Market Intelligence*.

---

## 0:00 - 0:30 // THE PROBLEM & VISION
> *"Every single day, enterprise GTM, compliance, and security teams are blind to dynamic signals occurring on the open web. Traditional methods rely on manual searches or static, stale feeds. Today, we're introducing **AEGIS** — an Autonomous Enterprise Intelligence Operating System that continuously monitors, scraper-patrols, remembers relationships, and acts automatically."*

---

## 0:30 - 1:15 // INITIATE SCAN
1. **Show Dashboard**: Point out the dark, cyberpunk operations-terminal layout:
   > *"Welcome to the AEGIS Command Center. This is not a chatbot. It is a cinematic multi-agent intelligence suite."*
2. **Type the Query**: Input `"Monitor OpenAI competitors"` in the command deck.
3. **Set Focus Checklist**: Check `Security Risk`, `Hiring Signal`, and `Pricing Shift`.
4. **Click INVESTIGATE**: 
   > *"Let's deploy our agent fleet to monitor OpenAI's top competitors for emerging threats, hiring surges, and strategic GTM pivots. We hit Investigate."*

---

## 1:15 - 2:00 // LIVE COGNITIVE FEED (Show Streaming Steps)
1. **Point to Cognition Stream Panel**:
   > *"As we speak, our LangGraph multi-agent loop begins executing. The live SSE Cognition Stream terminal shows the Scout agent running dynamic queries concurrently using the **Bright Data SERP API** to discover competitor articles."*
2. **Show Scraper dispatches**:
   > *"Next, the Investigate node fires. It takes those target competitor links and crawls them using **Bright Data Web Unlocker** rotating proxies to bypass standard Cloudflare restrictions, and dynamically launches **Bright Data Scraping Browser** over Playwright for JS-heavy interfaces."*
3. **Show Realtime Signal Radar alerts**:
   > *"In the Live Threat Beacons radar, we immediately capture incoming signals extracted using the low-latency Mistral model on **AI/ML API**: we detect a major security credential leak on a public repository, alongside a strategic hiring surge of 430 roles at Anthropic."*

---

## 2:00 - 2:30 // PERSISTENT GRAPH MEMORY & AUTOMATED WORKFLOWS
1. **Highlight the D3 Memory Graph**:
   > *"As these entities are discovered, they are dynamically registered inside **Cognee's persistent memory system**. In the bottom-left panel, Cognee constructs an interactive, semantic entity-relationship graph in real time. Because of Cognee, if we scan tomorrow, the agent remembers Anthropic's layoffs or pricing from yesterday, maintaining cross-scan intelligence."*
2. **Point to TriggerWare Logs**:
   > *"Because a critical credentials leak was detected, pushing our risk score above 7.0/10.0, our Synthesize node automatically dispatched a `HIGH_RISK_DETECTED` webhook to **TriggerWare** to lock down the threat. We see the automated dispatches status: DELIVERED."*

---

## 2:30 - 3:00 // REVIEW & SUMMARY
1. **Review report card**:
   > *"Our Synthesis agent, running the strong GPT-4o model via **AI/ML API**, compiles a structured executive briefing. We have a threat score of 7.5, clean compliance directives, and a downloadable briefing report."*
2. **Closing Pitch**:
   > *"With Bright Data unlocking the live web, AI/ML API providing intelligent routing, Cognee providing deep entity memory, and TriggerWare delivering action dispatches, AEGIS bridges the gap between passive reporting and autonomous action. Thank you."*
